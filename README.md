# 🩺 Disease Prediction & Health Recommendation System

[![Python](https://img.shields.io/badge/Python-3.10+-3776AB.svg?style=flat&logo=python&logoColor=white)](https://www.python.org/)
[![Scikit-Learn](https://img.shields.io/badge/Scikit_Learn-Healthcare_ML-F7931E.svg?style=flat&logo=scikit-learn&logoColor=white)](https://scikit-learn.org/)
[![Flask](https://img.shields.io/badge/Flask-Web_Framework-000000.svg?style=flat&logo=flask&logoColor=white)](https://flask.palletsprojects.com/)

A Machine Learning-based healthcare web application developed using **Flask** and **Scikit-Learn**. The system predicts probable health conditions based on user-reported symptoms and provides tailored dietary guidance and precautionary measures.

---

## 🌟 Key Capabilities

- **Symptom-Based Classification**: Multi-class classification model mapping input symptoms to health conditions.
- **Dietary Suggestions**: Recommends appropriate foods to consume and avoid based on predicted health state.
- **Precautionary Steps**: Outlines preventive health steps to manage symptoms effectively.
- **Web UI**: Simple, accessible interface for interactive symptom input and medical guide viewing.

---

## 🛠️ Tech Stack & Workflow

- **Machine Learning**: Scikit-Learn (Decision Trees / Random Forest / Naive Bayes)
- **Data Engineering**: Pandas, NumPy
- **Backend Application**: Flask (Python)
- **Frontend Interface**: HTML5, Vanilla CSS3, JavaScript

---

## 🚀 Quickstart & Setup

```bash
# 1. Clone repository
git clone https://github.com/JaiswalKritika/Disease-Recommendation-System-using-machine-learning.git
cd Disease-Recommendation-System-using-machine-learning

# 2. Install dependencies
pip install -r requirements.txt

# 3. Launch application
python app.py
```
